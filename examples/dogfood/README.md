# POKit Dogfood Examples

This directory contains dogfood outputs generated while validating POKit against a real Linear workspace.

These files are examples only. The public POKit template should not keep a user's live generated artifacts under `artifacts/`.

Recommended policy:

- Keep public, reusable examples under `examples/`.
- Keep local or team-specific generated outputs under `artifacts/`.
- Review generated artifacts before committing them to a public repository.
- Store sensitive customer data, credentials, and private project details outside the public repo.
