# POKIT-89 Definition Example

This directory is a public-safe, redacted exemplar for the POKit Definition Pipeline.

It shows how a raw idea becomes:

- a Korean PRD draft
- a data contract with provider, cost, copyright, and privacy gates
- acceptance criteria
- a Linear sub-issue dry-run

Local working drafts may live under ignored `artifacts/profiles/...` paths. Release-facing evidence should point here or to another redacted public path.
